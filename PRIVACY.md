# Politica de privacidad - shorts-uploader

shorts-uploader es una herramienta personal que sube videos a un unico canal de YouTube, el del propio autor.

- Usa la YouTube Data API solo con el permiso `youtube.upload`, para subir videos. No lee, edita ni borra videos existentes.
- No recolecta, guarda ni comparte datos de otras personas.
- El token de acceso se guarda solo en la computadora del autor y no se envia a ningun servidor propio ni de terceros.
- El acceso se puede revocar en cualquier momento desde https://myaccount.google.com/permissions.
